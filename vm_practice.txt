Установил Oracle VirtualBox, настроил виртуальную машину, установил на неё Docker. Разобрал, как инженеры работают с облачными серверами через удалённый доступ с ssh. Также опробовал некоторые команды для манипуляций с текстом:

echo "=== Проверка процессов ==="
ps aux | grep nginx

echo "=== Проверка контейнеров ==="
docker ps -a

echo "=== Проверка портов ==="
ss -tulpn | grep -E "8888|80"

echo "=== Проверка доступности ==="
curl -s http://localhost:8888 | head -10

Сделал отчёт:

1. Проверка процессов:
   - Nginx запущен (master process и worker processes).
   - Команда: ps aux | grep nginx

2. Проверка контейнеров:
   - Запущен контейнер с Nginx (ID: 9383ab23812d).
   - Порт 8888 проброшен на 80-й внутри контейнера.
   - Лишние контейнеры удалены через docker container prune -f.

3. Проверка доступности:
   - curl http://localhost:8888 на ВМ возвращает HTML-страницу Nginx.
   - Страница доступна внутри ВМ, но не открывается с хоста.

4. Сетевые настройки:
   - IP ВМ: 10.0.2.15 (интерфейс enp0s3).
   - ВМ в NAT-сети, поэтому с хоста адрес не доступен.

5. Вывод:
   - Nginx работает корректно.
   - Для доступа с хоста нужно настроить проброс портов в VirtualBox.
